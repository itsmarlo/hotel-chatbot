# Bellhob Hotel Assistant

An academic demonstration for a fictional hotel. It answers questions from authored policies
and creates synthetic reservations only after the guest confirms a quote. No payment is taken.

The running Space uses multilingual semantic retrieval and the trained intent model. The
larger Qwen interpreter is available in the [project repository](https://github.com/itsmarlo/hotel-chatbot)
for local evaluation. The repository may require access from its owner.
